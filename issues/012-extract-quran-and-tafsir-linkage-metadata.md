# Extract Qur'an and tafsir linkage metadata

## Goal
Connect ayat to tafsir, scholarly usage, rulings, admonitions, and language benefits.

## Tasks
- [ ] Detect ayah references.
- [ ] Link tafsir passages.
- [ ] Capture how scholars use the ayah as evidence.
- [ ] Extract language points tied to the ayah.
- [ ] Extract rulings and principles derived from the ayah.

## Acceptance
Selecting a translated verse retrieves the original Arabic ayah and relevant scholarly explanations.
