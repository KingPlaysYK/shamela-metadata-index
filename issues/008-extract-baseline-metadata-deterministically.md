# Extract baseline metadata deterministically

## Goal
Use local deterministic extraction before AI to reduce cost and improve consistency.

## Tasks
- [ ] Detect Qur'an references.
- [ ] Detect hadith references.
- [ ] Detect book/source references.
- [ ] Detect common claim markers.
- [ ] Detect definitions and classifications.
- [ ] Detect principles, exceptions, conditions, disagreement, and consensus.

## Acceptance
Every extracted item has exact Arabic evidence and citation.
