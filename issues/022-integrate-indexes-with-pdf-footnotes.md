# Integrate indexes with PDF footnotes

## Goal
Generate useful footnotes from selected words, names, ayat, hadith, or passages.

## Tasks
- [ ] Search original normalized Arabic, not English.
- [ ] Classify selection type.
- [ ] Retrieve by selected footnote type.
- [ ] Support up to 10 sources.
- [ ] Add “Explain Further”.
- [ ] Use source modal for every citation.

## Acceptance
PDF footnotes behave like a scholar annotating the book with grounded sources.
