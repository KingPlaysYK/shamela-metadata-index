# Extract language lexicon metadata

## Goal
Build rich language metadata for roots, terms, definitions, derivations, proverbs, poetry, and usage.

## Tasks
- [ ] Extract root meanings.
- [ ] Extract non-root word meanings.
- [ ] Extract derivation explanations.
- [ ] Extract multiple meanings.
- [ ] Extract Qur'an/hadith evidence used for language.
- [ ] Extract poetry/proverb examples.
- [ ] Mark contemporary usage only where supported.

## Acceptance
Word analysis can cite exact lexicon evidence.
