# Integrate indexes with word analysis

## Goal
Use metadata and indexes to improve word analysis.

## Tasks
- [ ] Retrieve exact word/root evidence.
- [ ] Use multiple lexicons.
- [ ] Cite all used evidence.
- [ ] Open exact source text.
- [ ] Avoid irrelevant fallback sources.
- [ ] Mark AI-generated content where no RAG evidence is used.

## Acceptance
Word analysis is grounded, relevant, and source-checkable.
