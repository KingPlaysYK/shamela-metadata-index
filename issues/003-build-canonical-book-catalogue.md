# Build canonical book catalogue

## Goal
Create a single catalogue that can answer: which books exist, who wrote them, what field they belong to, which edition is used, and whether full text is available.

## Tasks
- [ ] Import Shamela book info.
- [ ] Add author full names and death dates.
- [ ] Add field/category taxonomy.
- [ ] Mark source priority and edition preference.
- [ ] Mark whether full text is available.
- [ ] Mark whether metadata/index is built.

## Acceptance
The app can answer how many books by a given author exist and what status each book has.
