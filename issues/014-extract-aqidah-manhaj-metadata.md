# Extract aqidah/manhaj metadata

## Goal
Capture creed, methodology, sects, warnings, loaded terms, and scholarly positions.

## Tasks
- [ ] Detect creedal definitions.
- [ ] Detect sect/group names.
- [ ] Detect praise/criticism of groups or individuals.
- [ ] Detect methodological principles.
- [ ] Record scholar/source priority.
- [ ] Preserve nuance and exact wording.

## Acceptance
Aqidah/manhaj footnotes retrieve relevant, source-based explanations.
