# Completion Checklist

The project is complete only when every selected book scope satisfies these gates.

## Repository

- [x] Local D-drive repository exists.
- [x] Existing app RAG data preserved on D drive.
- [x] GitHub repository exists.
- [ ] GitHub issues created for every task.
- [ ] Local repository pushed to GitHub after every major update.

## Per Book Or Author Scope

- [ ] Catalogue record exists.
- [ ] Author full name recorded.
- [ ] Author death date recorded where known.
- [ ] Author madhab recorded where known.
- [ ] Edition/editor/publisher recorded.
- [ ] Full Arabic text downloaded.
- [ ] Raw text provenance recorded.
- [ ] Original text preserved.
- [ ] Normalized Arabic search text generated.
- [ ] Page chunks generated.
- [ ] Paragraph chunks generated where possible.
- [ ] Logical chunks generated where useful.
- [ ] Baseline metadata extracted.
- [ ] Enriched candidate metadata extracted where useful.
- [ ] Evidence spans validated.
- [ ] Rejected/invalid claims reported.
- [ ] Lexical index built.
- [ ] Metadata-filtered index built.
- [ ] Semantic index built where useful.
- [ ] Graph/hypergraph relationships built where useful.
- [ ] Retrieval quality tests passed.
- [ ] App integration status recorded.

## Global Quality Gates

- [ ] No generated claim appears without exact evidence.
- [ ] No source citation appears unless source text can be opened.
- [ ] Non-numeric volume values are treated as section labels.
- [ ] Footnote retrieval searches original normalized Arabic, not English.
- [ ] Footnote types use consistent formatting rules.
- [ ] Source modal shows author, death, book, volume/section, page, edition, editor, publisher, and year when available.
