## Field Collections

- All Arabic language books: lexicons, grammar, morphology, rhetoric, poetry evidence, proverbs, adab/lughah, and usage works.

## Cross-Cutting Rule

Every book record must capture the author's madhab where known. This matters for fiqh, usul, hadith commentary, tafsir, and author-position analysis.

## Quality Rule

For each requested scope, the project must produce:

- source catalogue records
- raw Arabic text
- provenance and edition metadata
- normalized search text
- page/paragraph/logical chunks
- baseline metadata
- enriched candidate metadata where useful
- exact evidence validation
- lexical/metadata indexes
- semantic index where useful
- graph or hypergraph relationships where useful
- retrieval quality report
